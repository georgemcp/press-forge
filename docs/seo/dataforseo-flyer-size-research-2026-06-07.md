## Page strategy

Add `/tools/flyer-size-guide` as a guide page.

The answer block should include:

- Common US flyer trim: 8.5 x 11 inches
- Approximate metric equivalent: 216 x 279 mm
- 300 DPI trimmed pixel size: 2550 x 3300 px
- Common bleed: 0.125 inch on each side
- Full-bleed document: 8.75 x 11.25 inches
- 300 DPI full-bleed size: 2625 x 3375 px
- Other common flyer references: 5.5 x 8.5, 5 x 7, 4 x 6, A4, A5, A6
- Printer-specific acceptance caveat

The page should not claim that Trim Proof replaces a printer's size chart, supports every exotic custom size, repairs arbitrary existing PDFs, or guarantees printer acceptance. It should state the current built-in Trim Proof flyer profile clearly: 8.5 x 11 inch trim, 0.125 inch bleed, and 0.25 inch safe margin.
