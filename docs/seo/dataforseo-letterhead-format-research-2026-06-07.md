## Page strategy

Add `/tools/letterhead-format-guide` as a guide page.

The answer block should include:

- Proper letterhead elements: logo, business name, address, phone, email, website, and optional legal/footer details
- Standard US letterhead size: 8.5 x 11 inches
- A4 reference: 210 x 297 mm
- 300 DPI trimmed pixel size for US Letter: 2550 x 3300 px
- Optional 0.125 inch bleed when artwork reaches the edge
- 300 DPI full-bleed size: 2625 x 3375 px
- Margin and safe-area guidance
- Printer-specific acceptance caveat

The page should not claim that Trim Proof replaces Microsoft Word templates, repairs every existing document, guarantees printer acceptance, or supports every possible office-document workflow. It should state that Trim Proof focuses on generated print-ready PDF/X proof output for supported letterhead jobs.
