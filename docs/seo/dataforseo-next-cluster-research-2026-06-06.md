## SERP Notes

DataForSEO organic SERP refresh for `proofing software` showed PageProof, Wrike, StreamWork, Reddit, Gartner, QuickReviewer, WeAproove, and Adobe Workfront in the top visible results. That SERP is mostly client approval, markup, review routing, and vendor comparison intent.

Implication: Trim Proof should not claim to be a full approval suite. The page should explicitly separate client approval software from print-production proof checks, then position Trim Proof as the latter.

## Build Decision

Implemented pages:

- `/tools/online-proofing-software`: guide page for proofing software searches, with clear limits around approval workflows.
- `/tools/prepress-checklist`: practical guide for prepress checklist, print file requirements, and how-to-prepare-files-for-printing searches.
- `/tools/prepress-automation-software`: product-led software page for prepress and automation searches.
- `/tools/flyer-pdf-template`: supported product-template page.
- `/tools/postcard-pdf-template`: supported product-template page.
- `/tools/letterhead-pdf-template`: supported product-template page.

Deferred:

- `menu pdf template`: measurable volume, and the menu product profile now exists. Keep the dedicated menu template page in the supported product-template cluster.
- Broader print-file setup pages beyond the checklist: exact demand was low in this refresh, so expand only after Search Console shows impressions around product-specific file setup terms.
